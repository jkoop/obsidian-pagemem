# Pagemem

Pagemem (read "page mem") is an (Obsidian)[https://obsidian.md] plugin for memorizing entire notes.

Features:
- Dead simple UI
- Only type the first letter of each word
- The more you review the note, the less often you need to review the note (spaced repetition)

## Usage

### Creating a memory note

1. Add the tag to your note: `pagemem`

That's it. Done.

### Reviewing memory notes

Open the note like you would any other note. The UI will then require you to type the first letter of each word in order (case-insensitive). E.g. (the example note)[/Example note.md] will require you to type `MitfotmbwdoiiesarwnIitroiotftpoifaIpecnbriwbiflropitdMliudafoa`.
